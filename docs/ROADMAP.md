# Roadmap

Each phase ends in something you can run. Items are checked off as they land.

## Phase 1 - Foundation ✅

- [x] CMake build, dependencies fetched automatically (SDL3, glm, Dear ImGui, doctest)
- [x] Logging with pluggable sinks
- [x] ConVars / ConCommands with self-registration, flags (archive, cheat, replicated, notify), min/max clamping, change callbacks
- [x] Command buffer: `;` / newline separation, quotes, `//` comments, `wait`, `alias`, `exec`, `toggle`, `incrementvar`, `find`, `help`, `cvarlist`
- [x] Virtual filesystem with ordered search paths
- [x] SDL3 window + OpenGL 4.5 core context
- [x] Key bindings with Source semantics (`+cmd` held buttons, multiple keys per button), saved to `config.cfg`
- [x] Fixed-tick server loop (66 tick) with variable-rate rendering and interpolation
- [x] Client/server split over an in-process loopback channel, UserCmds and snapshots
- [x] Noclip movement
- [x] Developer console with history and tab completion
- [x] Debug overlays (`cl_showfps`, `cl_showpos`), PNG screenshots
- [x] Dedicated server mode (`-dedicated`) with stdin console
- [x] Unit tests, smoke test script, CI on Linux and Windows

## Phase 2 - Rendering basics ✅

- [x] Texture loading (PNG/TGA/JPEG via stb_image), cached, sRGB, mipmaps, anisotropic filtering
- [x] Missing textures/materials show Source's magenta/black checker
- [x] Material system: `.kmt` KeyValues files (`LitGeneric`/`UnlitGeneric`, `$basetexture`, `$color`, `$alpha`, `$alphatest`, `$nocull`, `$selfillum`, `$texscale`, `$surfaceprop`), auto-material from a bare texture, `mat_reloadall`
- [x] KeyValues parser (shared with entities and scripts later)
- [x] Model loading: glTF 2.0 (`.glb`) with per-primitive materials, cached
- [x] Debug draw API (lines, boxes, crosses, axes with lifetimes), `r_showbounds`, `r_drawaxis`, `debug_drawline`
- [x] Skybox (cubemap, `r_skyname`)
- [x] Shader hot reload when files change on disk (`r_shader_hotreload`)
- [x] HDR render target, MSAA (`mat_antialias`), ACES tonemapping, gamma-correct output
- [x] Crosshair, `setpos` / `setang` / `getpos`, keyboard look (`+left`, `+right`, `+lookup`, `+lookdown`)
- [x] Procedural placeholder art generated by `tools/gen_dev_assets.py`

## Phase 3 - Map pipeline ✅

- [x] Read TrenchBroom / Quake `.map` files, standard and Valve 220 formats (brushes + entities)
- [x] `kbsp`: brush polygons, solid-leaf BSP tree, faces filtered through the tree (CSG for free), writes `.kbsp`
- [x] Portals, flood fill from entities, leak detection with a path, outside removal
- [x] `func_detail` (doesn't split the BSP or block vis), `tools/toolsskybox`, `tools/toolsnodraw`, player clip, brush entity submodels
- [x] PVS (base portal-flow vis, like `vvis -fast`)
- [x] Baked lightmaps: point lights, sun with shadows, sky ambient occlusion; HDR atlas
- [x] Runtime: `.kbsp` loading with validation, PVS + frustum culling, lightmapped shader, `prop_static`, spawn at `info_player_start`
- [x] `map <name>` with completion, `maps`; maps compile automatically during the build
- [x] TrenchBroom game config + FGD in `tools/trenchbroom/`; test map generator `tools/gen_test_maps.py`
- [x] Tests: compiled-room contents, traces, inside-only faces, vis, round trip, corruption
- [ ] Full anti-penumbra vis (tighter PVS for big maps)
- [ ] Radiosity bounces, `light_spot`, ambient samples for props
- [ ] T-junction fixing and coplanar face merging

## Phase 4 - Movement and collision ✅

- [x] Box traces against brushes through the BSP (Quake 3 style, with axial bevel planes from the compiler)
- [x] Source-style player movement: ground/air acceleration, friction, gravity, air strafing, step-up (18), stay-on-ground for stairs and slopes, crouch (with in-air leg tuck and stand-up check), jumping (57 units)
- [x] `noclip` (cheat), `sv_gravity`, `sv_accelerate`, `sv_airaccelerate`, `sv_friction`, `sv_stepsize`, `sv_autobunnyhopping`
- [x] Movement is a pure shared function (`shared/gamemovement`), ready for client prediction
- [x] Tests: landing, max speed, walls, sliding, jump height, steps vs blocks, crouch, air strafing, noclip, box traces
- [ ] Ladders, water, edge bevels for non-axial brush edges

## Phase 5 - Entities and game module ✅

- [x] Entity system with a class factory (`LINK_ENTITY_TO_CLASS`), key/values, think, touch, use, inputs
- [x] Map entities spawned from the BSP entity lump; brush entities with their own collision brushes
- [x] Entity I/O: `"OnPressed" "door1,Open,,0,-1"` connections with delays, parameters, fire limits, wildcards, `!activator`/`!caller`/`!self`/`!player`; `developer_io 1` traces it; `ent_fire` (cheat)
- [x] Entities: `func_door` (doors, elevators), `func_button`, `trigger_once`, `trigger_multiple`, `trigger_teleport`, `logic_relay`, `logic_timer`, `logic_auto`, `math_counter`, `point_message`, `func_brush`/`func_wall`/`func_illusionary`, `prop_dynamic`, `info_target`, `info_teleport_destination`
- [x] Movers push and carry the player; +use on buttons and doors
- [x] Game code in its own library (`game/`, `k_game`) behind `IGameServer`
- [x] Entity snapshots with a model table; client interpolates entities; center-screen messages
- [x] FGD entries for all entities; devroom has a door, button, elevator, triggers and messages
- [ ] Load the game as a shared library at runtime (needs a cross-module cvar/console interface)
- [ ] Rotating doors, `func_tracktrain`, sounds on movers

## Phase 6 - Physics and audio ✅

- [x] Jolt Physics: static world from convex brush hulls, kinematic bodies for doors/lifts, dynamic `prop_physics` (convex hull of the model), unit conversion at the boundary
- [x] Props block the player, get pushed when walked into, ride lifts; `+use` picks up light props, `+attack` throws
- [x] Audio with miniaudio: sound scripts (`scripts/sounds.txt`: random waves, pitch ranges, sound levels, loops), 3D positional playback that follows entities, device-less fallback, `-nosound`, `play`, `volume`, `snd_mute`, `snd_show`
- [x] Footsteps, jump/land, door move/stop, button press, physics impacts, `ambient_generic`
- [x] Placeholder sounds generated by `tools/gen_sounds.py`
- [ ] Soundscapes (DSP/reverb per area), occlusion
- [ ] Physics constraints, ragdolls, breakables, prop damage

## Phase 7 - Networking ✅

- [x] UDP sockets (POSIX + Winsock) and a Quake-style net channel: sequencing, acks, one in-flight reliable block, unreliable messages, ping/loss/bandwidth stats, timeouts, `net_fakeloss`/`net_fakelag`
- [x] Connectionless handshake (`connect`/`accept`/`reject`), passwords (`sv_password`), `sv_maxplayers`, `info` query
- [x] Multiplayer server: up to 16 clients, listen servers (`map` + `sv_listen`, `hostport`) and dedicated servers
- [x] Delta-compressed snapshots against each client's acknowledged baseline (field masks per entity)
- [x] Replicated cvars (`FCVAR_REPLICATED`) sent on join and on change
- [x] Client-side prediction with the shared movement code (including brush entities), error smoothing (`cl_smoothtime`), `cl_predict`, `cl_showerror`
- [x] Entity interpolation buffer `cl_interp` seconds in the past with a slewed client clock
- [x] Lag compensation: player position history, hitscan (`+attack`) rewinds targets to what the shooter saw (`sv_lagcompensation`)
- [x] `connect <ip[:port]> [password]`, `disconnect`, `status`, `net_graph 1`; players block each other; placeholder player model
- [x] Tests: reliability under 30% loss, sockets, delta round trips, in-process server + two UDP clients, prediction accuracy, password rejection, lag compensation; smoke test runs a dedicated server and a remote client as separate processes
- [ ] Bit-packing / quantized origins and angles; fragmenting very large snapshots
- [ ] Server browser / master server, NAT punch-through

## Phase 8 - Polish ✅ (core items)

- [x] Health, damage, death and respawn (`sv_respawntime`), Source-style fall damage, `trigger_hurt`, `kill`, kill feed
- [x] HUD: health, hit markers, damage flash, death screen, kill feed (`hud_draw`)
- [x] Main menu on Escape: resume, new game (map list), join, options (name, sensitivity, FOV, volume, vsync), disconnect, quit
- [x] Particles (dust, sparks, blood) and impact decals from server temp entities (`r_decals`, `r_particles`)
- [x] Packed content: `.kpk` archives mounted after loose files, `kpak` tool, audio decoded from memory so everything can live in a pack
- [ ] Normal/specular maps and env_cubemap reflections (needs directional lightmaps for world surfaces)
- [ ] Vulkan or Metal backend (enables macOS)
